## Machine Learning Project

- Download dataset from [Kaggle](https://www.kaggle.com/datasets/grassknoted/asl-alphabet?resource=download)
- Move zip folder to project directory, unzip, and then delete the zip file
- Rename dataset from `archive` to `Sign_Language_Dataset`
- Install packages with `pip3 install scikit-learn Pillow tqdm`
- Run `python3 main.py`
